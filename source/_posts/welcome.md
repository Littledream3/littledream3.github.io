# 👋 Hi，我是天小梦

欢迎来到我的小站。我是一名即将毕业的电子信息硕士，喜欢游戏，也在学习如何把想法做成可玩的作品。这个博客使用 **Hexo + Butterfly** 搭建，部署在 **GitHub Pages**。

## 这里会写些什么

- 🎮 **游戏作品**：独立制作的游戏、玩法演示与制作记录。
- 🧩 **玩法策划**：游戏系统拆解、新模式设计和规则推演。
- 🛠️ **开发笔记**：Unity、Unreal Engine 的实践与遇到的问题。
- 📚 **学习随记**：值得保存的技术知识与个人思考。

## 怎么写新文章

```bash
# 生成文章文件
npx hexo new post "文章标题"

# 也可以在 source/_posts/ 中新建 Markdown 文件
# 并在文件开头填写标题、日期等信息
```

## 怎么看效果

```bash
npm run server  # 本地预览
npm run build   # 生成静态页面
```

如果想先看看我做过什么，可以从[作品集](/categories/portfolio/)开始；想认识我，也欢迎读读[关于我](/about/)。
